Fix the review's blockers and the cargo, lock and save defects

Closes the three blockers from the 2026-09-19 review plus items 4, 8, 9, 10,
11, 12 and 13. Every fix is falsified: each new check was run against the
unfixed code and confirmed to fail.

Blocker 1 - dropped cargo was unreachable and leaked. The kill handler called
dropCargo and threw the return value away, so nothing put the canister in the
list the collision scan walks: the scoop never fired, and the mesh survived
every prune and every jump. Wreckage now goes through traffic.addWreckage,
which puts it under the collision loop, the laser raycast, prune and dispose
at once. isTraffic keeps canisters and capsules out of the cap so scooping
cannot starve a system of ships. The NaN the review warned about was real and
came from turnRate, not speed: steerToward computes s.turnRate * dt, and
undefined * dt poisons the quaternion within two seconds.

Blocker 3 - a semantically broken save bricked the game. loadGame checked only
that the JSON parsed and the seed matched, then handed the record to an
unguarded Object.assign; a string cash broke the station screen and an
out-of-range currentSystem threw on arrival, on every boot. validateSave
rejects rather than repairs, matching the path broken JSON already takes.

Item 4 - the day model. A day is spent by a jump and by a dock; the code was
right and three descriptions were wrong. The stale deadline assertion that
allowed hops === days is tightened to the form the courier rule already used.

Item 8 - a routine dock armed the same 1.4 s cooldown as Escape, so a quick
dock-then-undock came back to a dead mouse. Docking, death and the chart now
release quietly; Escape still arms the delay.

Items 9 and 10 - a system change orphaned the player's missiles and kept a
target lock pointing into the destroyed scene. dropMissile and clearMissiles
replace the bare length = 0, and the lock is cleared with the rest.

Item 11 - the contract id did not name the commodity, so two different cargoes
on one route with the same tonnage and deadline collided and the duplicate
guard refused a genuinely different job. The id now carries the commodity and
is built in one place, offerId.

Item 12 - stakeOf used || where the zero case was the answer, pricing a full
hold as though the whole tonnage were still to be bought. The old test had
baked that in as correct and is rewritten.

Item 13 - the e2e mouse check asserted two things that are true at zero
requests, so a regression that stopped the game asking entirely would pass.
It now counts the requests and fails on the never-ask regression.

Item 7 and blocker 2 were already fixed by f152e95; the review read the commit
before it.

678 unit tests, 81 e2e, build 721 kB / 196 kB gzip.
