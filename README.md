<h1 align="center">ELITE: DEEP SPACE</h1>
<p align="center">Современная 3D-реинкарнация космической торговой симуляции Elite (1984) — ретро-векторная эстетика на Three.js</p>

---

Галактика из 64 процедурно сгенерированных звёздных систем, связанных графом
прыжковых маршрутов. 19 товаров, 8 типов правительств и экономик, лестница
рейтинга от HARMLESS до ELITE, стыковка с вращающейся станцией Coriolis,
ведьминское пространство, топливозаборник, спасательная капсула.

Графика — компромисс между оригиналом и современностью. Космос больше не
плоский фон: процедурное небо строит 9000 звёзд вдоль галактической полосы,
эмиссионные туманности по спектральным линиям и пылевые полосы. Корпуса —
физически корректные материалы (`MeshStandardMaterial`) с металличностью и
шероховатостью, которые отражают процедурную environment-пробу: металл ловит
тёплый блик звезды сверху и холодную заливку зенита снизу, камень остаётся
матовым, станция — самая полированная поверхность в кадре. Силуэт несёт
тонкая каркасная обводка (`EdgesGeometry`), затухающая по дистанции. Сверху —
bloom с ACES tone mapping.

- **Процедурная галактика** — MST-граф маршрутов гарантирует связность: ни одна
  система не изолирована, минимальная степень узла — 2.
- **Полёт** — кватернионная интеграция по локальным осям, намеренно
  не-ньютоновская («самолёт в космосе»), с инерцией, креном и форсажем.
- **Бой** — импульсный и лучевой лазеры с моделью перегрева, ракеты с
  самонаведением. Пираты атакуют проходами, **разрывают бой при тяжёлых
  повреждениях**, **втягиваются в драку, если рядом уже дерутся** и **пускают
  ракеты**, которые можно перекрутить или сбить лазером. Охвата (одновременного
  захода с двух сторон) нет: он был написан, измерен и откачен — замер показал,
  что пираты и так заходят под углом 76–122° друг к другу. См. `docs/DECISIONS.md`.
- **Торговля и репутация** — динамические цены по экономике, правительству и
  условиям мира, контрабанда, штрафы. Репутация с фракцией влияет на закупку,
  на то, как вас встречают, и на то, откроют ли патрули огонь.
- **Контракты** — доска заданий на станции: доставка, гуманитарный рейс,
  курьер, зачистка пиратов. Сроки, награды, репутация. Задания выводятся из
  того, что система производит, а её соседи — чего им не хватает. Взятая
  зачистка **меняет саму систему**: она превращается в укреплённое гнездо,
  которое ждёт вас у станции, и стихает, когда работа сделана.
- **Память мира** — системы помнят, что вы там сделали. Расчищенные трассы
  становятся безопаснее и оживлённее, убитые патрули — опаснее, накормленный
  голод дешевеет. Слухи в баре — про вашу историю.
- **Пояс астероидов** — четыре породы камня, различающиеся числом граней,
  цветом и материалом: базальт, гранит, металлический железняк и редкий лёд.
- **Станция** — 19 товаров, оборудование, ремонт, заправка, карта галактики
  в световых годах.
- **HUD** — Canvas 2D: сканер с отметками высоты, компас, проекция цели с
  упреждающей меткой, подсказки стыковки.
- **Звук** — процедурный синтез WebAudio, без единого файла-ассета.

## Играть

**https://alexanderkuzikov.github.io/Elite-Deep/** — играть прямо в браузере, без
установки. Это тот же самый один самодостаточный HTML-файл, что собирается
локально.

## Быстрый старт

Нужен **Node 22+** и Google Chrome (только для e2e-прогона).

```bash
npm install
npm run dev          # dev-сервер с горячей перезагрузкой

npm run build        # dist/index.html — один самодостаточный файл
npm test             # 624 юнита
npm run e2e          # 56 проверок в headless Chrome
npm run sim 200      # симулятор экономики: три карьеры на 200 прыжках
npm run check        # тесты + сборка + e2e
```

Собранный `dist/index.html` открывается двойным кликом по `file://` — без
сервера, без зависимостей, без сети.

**Управление:** `WASD` / стрелки — рули, `R`/`F` — тяга, `Space` — тормоз,
`Z` — форсаж, `M` — огонь, `N` — ракета, `T` — цель, `C` — стыковка,
`H` — прыжок, `O` — карта. На станции: `Enter` — купить/продать всё или взять
контракт, `1` — ровно одну тонну, `Tab` — переключить экран, `C` — отстыковаться
(или `Esc`).

## Стек

| Слой | Технология |
|------|-----------|
| Рендер | Three.js r186, EffectComposer → UnrealBloomPass → OutputPass, ACES tone mapping |
| Материалы | `MeshStandardMaterial` (metalness/roughness) + процедурная equirect-проба (`environment.js`) |
| Небо | Процедурное: 9000 звёзд, галактический пояс, туманности, пыль (`sky.js`) |
| Сборка | Vite 8 + vite-plugin-singlefile |
| Логика | Чистый ESM без зависимостей, детерминированный PRNG (mulberry32, value-noise 3D) |
| UI | Canvas 2D (HUD) + DOM (экраны станции) |
| Тесты | `node:test` (юнит) + puppeteer-core (e2e) |
| Звук | WebAudio, процедурный синтез |

## Статус

**v0.1.0** — играбельно: полёт, бой, торговля, стыковка, прыжки, карта,
рейтинг. Графика осовременена: процедурное небо с галактическим поясом,
PBR-материалы с environment-пробой, объёмные корпуса с затухающей обводкой.
624 юнита и 59 e2e-проверок зелёные.

Открытые вопросы — дизайнерские, а не технические, и перечислены в
`docs/CONTEXT.md`: должны ли зачистки доминировать по награде, показывать ли
взятый контракт дважды на доске, должен ли Docking Computer снимать сложность
стыковки.

## Публикация

Репозиторий готов к пушу. После первого пуша:

1. **Settings → Pages → Source → «GitHub Actions»** — включит
   `.github/workflows/pages.yml`, и игра станет доступна по ссылке (один
   самодостаточный HTML, без установки).
2. **Actions** — `ci.yml` прогонит юниты, сборку и e2e на каждый пуш.
