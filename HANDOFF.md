## 1. Что это

Современная 3D-реинкарнация *Elite* (1984) на Three.js: галактика из 64
процедурных систем, полёт, бой, торговля, контракты, стыковка с вращающейся
станцией, карта в световых годах. Собирается в **один самодостаточный HTML-файл**
без ассетов — вся графика строится процедурно.

**Играть:** открыть ссылку выше. Или собрать (`npm run build`) и открыть
`dist/index.html` двойным кликом — без сервера и без сети.

## 3. Как запустить

Нужен **Node 22+**. Chrome — только для e2e.

```bash
git clone https://github.com/AlexanderKuzikov/Elite-Deep.git
cd Elite-Deep
npm ci

npm run dev        # игра в браузере, с горячей перезагрузкой
npm test           # 628 юнитов (node:test)
npm run e2e        # 60 проверок в headless Chrome
npm run build      # dist/index.html — один самодостаточный файл
npm run sim 200    # симулятор экономики: три карьеры на 200 прыжках
npm run check      # тесты + сборка + e2e
```

Chrome для e2e ищется по стандартным путям Windows, Linux и macOS;
переопределяется переменной `CHROME_PATH`.

**Управление:** `WASD`/стрелки — рули, `R`/`F` — тяга, `Space` — тормоз,
`Z` — форсаж, `M` — огонь, `N` — ракета, `T` — цель, `C` — стыковка,
`H` — прыжок, `O` — карта. На станции: `Enter` — взять/купить всё, `1` — одну
тонну, `Tab` — переключить экран, `C` или `Esc` — отстыковаться.

## 5. Что сделано в последней сессии

Работа шла по принципу **«смотри на игру, а не на тесты»** — и почти каждая
находка была видна глазом, но подтверждалась замером.

**Исправлено (11 дефектов):**

| Дефект | Как найден |
|---|---|
| Пояс астероидов — поле проволочных шаров (89 % пикселей темнее 35) | снимок + замер по пикселям объекта |
| Четыре породы камня были неразличимы | следствие первой правки |
| Журнал сообщений нечитаем (контраст 1.74; двойная прозрачность 0.35 × 0.38 = 0.13) | снимок + замер контраста |
| Станция: подсказка «D undock» — D это roll-right и листает список | снимок |
| Станция: «Esc undock» — Escape не привязан нигде | снимок |
| Список рынка не следовал за выделением (`scrollTop` всегда 0) | снимок + замер обхода |
| Карта: «ENTER = select» — Enter не привязан нигде | снимок |
| **Клавиша огня M запускала ракеты** (3 → 2 и трассер одним нажатием) | замер с захваченной целью |
| За экраном станции рисовался полётный HUD (прицел поверх таблицы рынка) | снимок вкладки Contracts |
| Взятый контракт показывался на доске дважды | снимок |
| **Сохранение теряло последнюю станцию** — после перезагрузки и гибели игрока выбрасывало на Lave | аудит кругом по всем полям |
| Планета выглядела гранёным кристаллом (решётка value-шума) | снимок витрины |
| Флейк: `Math.random` в ИИ нарушал правило проекта | падение теста в полном прогоне |
| Лучевой лазер: «double damage, faster cycle» — на деле 1.7x и **медленнее** | аудит описаний против чисел |
| Fuel Scoops обещал скимминг топлива, которого нет | тот же аудит |

**Отменено замером (тоже результат):**

- **Охват** (фланги) — замер показал, что пираты и так заходят под 76–122°;
  очередь была артефактом стенда (неубранная скорость от `spawn`). Код удалён.
- **Тёмная станция на заголовке** — оказалась не станцией, а собственным
  градиентом экрана заголовка поверх неё.
- **Звезда «пересвечена»** — выше 240 не выбито ни одного пикселя.
- **Станция «прозрачная»** — материал `FrontSide`, против чёрного неба силуэт
  сплошной; точки оказались рёбрами дальних граней.
- **Колонки рынка «съехали»** — замер `getBoundingClientRect`: совпадают
  попиксельно.

**Крупные добавления:** контракты на зачистку делают систему «укреплённым
гнездом»; симулятор экономики считает три карьеры; HUD масштабируется по высоте
окна; репозиторий опубликован, CI и Pages работают.

## 6. Открытые вопросы — все дизайнерские

Технических долгов нет. Осталось три решения, и по каждому есть числа.

### 6.1. Docking Computer (#8)

За 2500 CR он **расширяет створ** (offset 130 против 46, угол 0.9 против 0.42),
а не летит за игрока. Вопрос: должен ли он **снимать** сложность стыковки, а не
облегчать её?

**Моя позиция:** текущее поведение правильное — компьютер, который стыкует сам,
удаляет целую фазу игры. Записано в ADR.

### 6.2. Курьеры редки (#11)

Резерв слота под зачистку отнял место у грузовых строк:

| форма доски | досок из 320 |
|---|---|
| `delivery + delivery + bounty` | **198** |
| `delivery + delivery + delivery` | 48 |
| `delivery + delivery + relief` | 31 |
| `delivery + delivery + courier` | 13 |
| остальные | 30 |

Курьеры — **8 %**, зачистки — 66 %, «только груз» — 27 %.

**Варианты:** (а) резервировать слот и под курьера — тогда доска всегда «курьер +
груз + зачистка», форма предсказуемая, но каждый вид работы доступен; (б) брать
курьера, когда у системы мало излишков; (в) оставить — доставка по замыслу «хлеб
доски».

**Почему я не тронул:** это обмен одного на другое, а не улучшение, и решать
владельцу.

### 6.3. Зачистки доминируют по награде (#13)

Жадный по награде командир в симуляторе берёт **16 зачисток и ни одной грузовой
работы**, проводя 136 дней из 200 в зачистке: зачистка платит больше одного
торгового рейса.

**Но:** симулятор **не моделирует смерть**, поэтому «доминирование» — отчасти
свойство модели, а не игры. В игре за это платят риском.

**Варианты:** (а) поднять награды грузовых работ; (б) сделать зачистку дороже по
времени; (в) оставить — риск и есть цена.

## 7. Грабли и конвенции

Полный список — в [`AGENTS.md`](AGENTS.md). Самое дорогое:

- **Снимок показывает результат, а не причину.** Три раза за сессию глаз видел
  дефект там, где замер его не находил. Прежде чем менять то, что «плохо
  выглядит», измерь.
- **Если правка одной константы улучшает одно и портит другое — ищи структурную
  причину.** Фон карты гасил не только мир, но и HUD; подъём непрозрачности
  улучшил одно и убил другое, потому что причина была в порядке вызовов.
- **Текст, обещающий поведение, — это код.** За сессию найдено **пять** случаев:
  «D undock», «Esc undock», «ENTER = select», «double damage, faster cycle»,
  «skim fuel from a star surface». Все написаны один раз и никогда ни с чем не
  сверялись. Выноси легенды в константы и проверяй против источника истины.
- **Если тест падает не всегда — источник случайности в проверяемом коде.** И
  флейк хуже отсутствия теста: он учит перезапускать прогон вместо того, чтобы
  читать вывод.
- **Тест на сохранение, написанный по памяти, проверяет память автора.**
  Заполняй все поля и сравнивай все.
- **Тест может утверждать дефект как требование.** Меняя природу вещи, перечитай
  тесты, которые её описывают.
- **Путь, который разрешается на одной машине, — это не зависимость.** Локально
  всё было зелёным; CI упал в первом же прогоне. CI — первая машина, которая не
  твоя.

**Конвенции:** документация и комментарии по-русски, код и идентификаторы
по-английски. Комментарии объясняют *почему*, а не *что*, и ссылаются на замер.
Каждый модуль имеет именованные экспорты плюс зеркальный `export default`.

## 8. Что делать дальше

1. **Решить один из трёх вопросов раздела 6** — они единственное, что осталось.
2. **Играть.** Ничто не заменит десяти минут за игрой: все дефекты этой сессии
   найдены глазами, а не сканером.
3. Если брать новую функциональность — сначала `docs/CONTEXT.md` (что уже
   пробовали) и `docs/DECISIONS.md` (почему так, а не иначе). Там записаны и
   **отменённые** решения — их не надо пробовать заново.

### Технические заметки

- **`gh` не авторизован**, пуш шёл по токену. Если токен отозван — нужен новый
  (`Contents: Read and write` для fine-grained).
- **Pages** включён (`build_type: workflow`); разворачивается на каждый пуш в
  `main`.
- **Ветка одна** — `main`. Пуш в неё запускает CI и деплой.
- **Скриншоты для README** лежат в `docs/screenshots/` и **коммитятся**;
  `e2e-shots/` — черновик прогона и в `.gitignore`.
