## Блокеры

**1. [src/sim/flight.js:149] Интеграция вращения — в мировом кадре, а не в кадре корабля, вопреки комментарию.**
Комментарий (дважды: шапка `applyRotation` и строка формулы) обещает правое произведение `q ⊗ dq` — вращение в собственном кадре корабля. Фактические кросс-члены (`pitch: dy=−qz·s`; `yaw: dx=+qz·s`; `roll: dx=−qy·s`) — это левое произведение `dq ⊗ q`, мировой кадр. Замер одного шага 1/60 после крена 90°: `|код − мировой| = 1.7e-5`, `|код − локальный| = 0.0118`. Следствие для игрока: при крене тянка тянет нос вдоль мировой вертикали `(0, −0.017, 1)` вместо локальной `(0.017, 0, 1)`, yaw→pitch не меняет курс — «bank and pull» из комментария к `RATES` не работает, roll assist инертен. Тесты гоняют только near-identity кватернионы. **Правка:** инвертировать знаки кросс-членов в трёх блоках (`dy=+qz·s, dz=−qy·s`; `dx=−qz·s, dz=+qx·s`; `dx=+qy·s, dy=−qx·s`), `dw` не трогать; добавить тест с предварительным креном и тест yaw+pitch (курс обязан измениться) — иначе регрессия недостижима для тестов.

**2. [src/main.js:412] Утечка `cockpitLight` при каждом входе в систему.**
`enterSystem` создаёт `WORLD.makeCockpitLight()` и делает `renderer.scene.add(cockpitLight)` (main.js:417); `teardownScene` (main.js:1227) снимает `root`, `sunLight`, `sunLight.target`, `planetLight` — но не его. Один `HemisphereLight` на каждый прыжок/респаун; в e2e ещё и цикл по каталогу систем. `session.systemLights` (main.js:262, 413) пишется и **нигде не читается** — похоже, это и был задуманный список для демонтажа. Тесты свет не считают, поэтому утечка не ловится. **Правка:** снимать по `session.systemLights`, удалить ручное перечисление; в e2e добавить проверку `children.filter(c => c.isLight).length` после N входов в систему.

**3. [src/sim/models.js:683] У `makeCoriolis` не построены боковые грани — слот висит в ~44 юнита над корпусом.**
Замер топологии: 68 треугольников, **0 треугольников в плоскостях `z=±h` / `x=±h`** (только 4 крышки `y=±h`), 24 вырожденных треугольника (из-за `ta = top[floor(i/4)]` — см. строку 687), 32 ребра с 3+ инцидентными гранями, Euler V−E+F = **18** вместо 2. «Юбки» стянуты к ромбам крышек, поэтому лицевая сторона — воронка, а не плоскость, хотя вершинные данные описывают срезанный куб, как и обещает комментарий. Луч по оси слота: первый hit корпуса на **z=86.7**, слот и рельсы стоят на **z=130.9** → отрыв **44 юнита** (30 % радиуса) при заявленном «the docking slot is a real object on the surface». Дыр в силуэте нет (0 промахов лучей), дефект виден с косого ракурса параллаксом. **Правка:** переписать индексы — по 2 треугольника на каждую из 4 боковых плоскостей плюс угловые срезы; закрыть тестом топологии (boundary=0, non-manifold=0, Euler=2, ≥1 треугольник в каждой из 6 граней) и тестом «плоскость слота лежит на поверхности».

**4. [src/sim/models.js:595] `makeAsteroid` рвёт замкнутое тело — офсеты по индексу неиндексированной геометрии.**
`IcosahedronGeometry`/`DodecahedronGeometry` не индексированы, копии одной вершины получают разные `offsets[i]` и расходятся: замер — **0 сваренных рёбер, 100 % открыты**, расхождение до 0.587 лок. ед. (25–30 % радиуса камня). `side: THREE.DoubleSide` (строка 625) маскирует дыры — прямое нарушение правила проекта «закрытые тела — FrontSide». Сквозных дыр в силуэте нет (лучи 0/400 промахов), заметен с касательных ракурсов. **Правка:** сварить вершины по позиции до наложения смещений (или ключевать offset по hash позиции) — ~10 строк; после этого убрать `DoubleSide`.

**5. [src/ui/station.js:200] Подсказка станции обещает `Enter` и `Tab`, которых нет в `BINDINGS`.**
`renderHint` печатает «Enter … all/accept», «Tab switch screen» (station.js:200, 208). В `src/core/input.js` привязок `Enter` и `Tab` **нет вообще** (проверено grep). Реально: activate = `fire` (KeyM) / `missile` (KeyN), смена вкладки = `throttleUp` (KeyR/ShiftLeft) — см. `handleDockedInput` (main.js:2239–2250). Игрок жмёт Enter — ничего не происходит. Это ровно класс «текст обещает поведение» из AGENTS.md, где уже зафиксированы три таких случая, и там же записано требование: тест, сверяющий подсказку с `BINDINGS` и падающий при расхождении. Такого теста нет. **Правка:** привести подсказку к фактическим клавишам и написать тест-сверку (текст подсказки ↔ `BINDINGS`).

**6. [src/main.js:2521] Деструктивное действие «new career» на `Shift` без предупреждения.**
`updateTitle` по `consume('throttleUp')` делает `PLAYER.create()` — стирает cash/kills/контракты. `throttleUp = ['KeyR', 'ShiftLeft']` (input.js:41), а guard от модификаторов (input.js:225) пропускает Shift. Титул достижим mid-flight по `pause` (main.js:2127), и там написано только про «R … erases the save» (main.js:2965) — про **Shift ни слова**. Одно случайное нажатие Shift на титуле уничтожает карьеру в памяти (on-disk save живёт до ближайшей стыковки, где перезапишется уже пустым). **Правка:** отдельная клавиша для new career (не из семейства throttle, не модификатор), опционально подтверждение; не смешивать с `R F throttle`, которую обещает `TITLE_CONTROLS`.

## Важно

- **[src/core/input.js:225] Guard модификаторов делает алиас `ControlLeft` мёртвым.** `throttleDown: ['KeyF', 'ControlLeft']` (input.js:42) недостижим: keydown самой Ctrl приходит с `ctrlKey === true` и отсекается. Хуже: пока Ctrl зажат, все остальные keydown отбрасываются — зажали Ctrl, потом F → тормоз мёртв. **Правка:** пропускать событие, если `e.code` — сам модификатор, либо убрать `ControlLeft` из таблицы.
- **[src/ui/hud.js:945] `drawDockingGuide`: текст без `fillStyle` и без обводки.** В ветке `guide.ok` цвет «DOCKING» — остаток предыдущего вызова (последний алерт — `danger`/`warn`), при зелёной рамке. Весь текст гайда («DOCKING», «SLOW DOWN», спидометр, cy = h·0.72 — слот станции, самый яркий объект кадра) идёт без `strokeText`-обводки, хотя проект сам замерил контраст 1.74 / 97 % ниже 3:1 и везде применил схему обводки. **Правка:** `fillStyle = HUD_COLOURS.ok` перед `fillText` + та же схема `strokeText` (`plate`, lineWidth 3k) что в `drawMessages`/`drawMouseHint`.
- **[src/core/audio.js:308] Написанное ≠ подключённое: `volumeAt`, `lockTick`, `stopAll`, `setMuted` не вызываются нигде в `src/`.** Вместе с ними мертвы `CUES.warn` и `CUES.lowFuel`. Следствия: взрывы играются на полной громкости на любой дистанции (докстринг `volumeAt` обещает distance falloff), прогрессивного warble при захвате нет, `stopAll` не зовётся на смерти, mute живёт только через main-обёртку. Тесты зелёные — они тестируют API, а не подключение. **Правка:** подключить или удалить API и выправить докстринги.
- **[src/ui/station.js:153] `moveSelection` пересобирает DOM каждый кадр.** `handleDockedInput` зовёт её по `held(...)` (main.js:2245), внутри — безусловный `render()`: `textContent = ''` + пересборка таблицы + два `getBoundingClientRect` (forced reflow). Удержание стрелки = 60 полных пересборок/с; из-за `wrap()` карусель 60 строк/с — конкретную строку удержанием не выбрать. Противоречит шапке файла («build once, then patch»). **Правка:** не рендерить, если индекс не изменился; порог повтора ~8–10 Гц; патч `class` вместо пересборки.
- **[src/sim/world.js `checkDocking`] Недостижимая ветка и мёртвые поля `DOCKING`.** `inside = d < R0*1.6` = 240, а `range` = 260 (ручной) / 460 (ассист) → ветка `d > clearance && d > limits.range` недостижима, `DOCKING.maxDistance` и `assist.range` не влияют ни на что (реальный радиус — магический 240 вне структуры). `limits !== null` в построении вердикта всегда true. **Правка:** `inside = d < limits.range` либо удалить поле и поправить комментарии.
- **[src/sim/world.js `stepTraffic`] Константа-обманка и незащищённые hooks.** `const playerFacingUs = true` с комментарием «the caller decides» — вызывающий не передаёт ни параметра, ни состояния. `hooks.onEnemyMissile` проверяется, `hooks.onEnemyShot` вызывается вслепую, `hooks` идёт без default — `{ onEnemyMissile(){} }` или `undefined` роняет кадр. **Правка:** `hooks = {}` в сигнатуре + guard как у ракет; `playerFacingUs` — параметром или удалить.
- **[src/sim/environment.js `buildProbePixels`] Полюс пробки инвертирован.** Внутри одной функции две несовместимые карты: `polar(v) = 2v−1` (v=0 → юг) и `dir.y = cos(v·π)` (v=0 → север); у `DataTexture` в r186 `flipY = false`. Замер: ярчайший тексель код записал `dir.y = +0.849`, `equirectUv` читает `−0.849` — глинт уходит под горизонт, зеркалятся глитч и блумы, рушится собственный контракт модуля («reflection and the sky agree»). **Правка:** `theta = (1 − v) * Math.PI`; заодно два ложных комментария про flip и «no PMREM pass required».
- **[src/sim/sky.js `buildStars`] `sizes[]` заполняется, но не используется.** Ни в геометрию, ни в материал (`size: 2.0`) массив не идёт — все звёзды одного размера, `SKY.minSize/maxSize` мертвы, комментарий «Size tracks brightness» лжёт. **Правка:** удалить массив и комментарий либо реализовать per-vertex size через `onBeforeCompile` под `gl_PointSize`.
- **[src/sim/flight.js:144 `LIMITS.pitch`] Лимит gimbal flip никогда не применяется.** Используется только `LIMITS.rate`; обещание «stop short of straight up» не выполняется (при текущей интеграции тангаж вообще крутится вокруг мировой оси — см. блокер 1). **Правка:** после фикса кадра — либо подключить clamp, либо убрать константу и обещание.
- **[src/ui/hud.js:823] `hudOverlayFor` отдаёт `'flight'` для неизвестного режима.** Ровно класс «провал в цепочке условий», записанный в AGENTS.md как прошлый баг (прицел поверх рынка): любой новый режим молча получит полётный HUD. **Правка:** перечислить все режимы явно, default — `'none'`.
- **[src/main.js:2233] В DOCKED `O` (chart) и `J` (jump) означают undock.** `handleDockedInput` трактует `chart` и `jump` как выход со станции, хотя `TITLE_CONTROLS` обещает «O chart». Проект сам завёл отдельный `leave` потому, что «one binding cannot mean both» — здесь исключение сделано. **Правка:** в DOCKED реагировать только на `dock`/`leave`; `O` — либо игнорировать, либо открывать карту.
- **[src/core/input.js:80] `escapeCapsule: ['KeyK']` — привязка действия, которого в игре нет.** Grep: только определение. Мёртвый binding хуже отсутствующего (проект уже убирал F5/F9 по этой причине). **Правка:** удалить или подключить механику.
- **[src/logic/economy.js:156] `driftFactor` солит от `com.base` — соль и gold дрейфуют идентично.** Оба `base: 11.0` → одинаковые `phase` и `noise1`, то есть два разных товара получают побитовый одинаковый дрейф. **Правка:** соль от `com.id` (или индекса), не от цены.
- **[src/logic/player.js:325] `refuel` может увести cash в минус при дробном cash.** `affordable = floor(cash/1.4)`, `cost = ceil(affordable*1.4)`; при cash = 9.85: affordable = 7, cost = 10 → cash = −0.15. Достижимо: цены на рынке дробные. **Правка:** `cost = Math.min(cost, p.cash)`.
- **[src/logic/factions.js:197] Комментарий «Poor systems suffer more, rich systems boom more» не реализован.** `if (c.id === 'BOOM') w *= 1;` — no-op, веса всех систем одинаковы. **Правка:** реализовать зависимость от `economy(id)` или удалить комментарий и no-op.
- **[src/logic/galaxy.js:167] Мёртвая переменная `factionRoll` сдвигает PRNG-поток.** Вычисляется (`r() + distRatio*0.35`), не читается — реально используется `fRoll` (строка 169). Лишний вызов `r()` меняет всю последовательность галактики. **Правка:** удалить обе строки; **внимание:** это изменит генерацию всех систем — прогнать тесты и e2e, в CONTEXT отметить как сознательную смену сида.
- **[src/logic/galaxy.js:392] `neighbors` сравнивает сырые единицы, докстринг обещает light years.** Функция вызывается только из `tests/galaxy.test.js` — мёртвый в проде экспорт с ловушкой (сам `distance` выше предупреждает про это). **Правка:** удалить `neighbors` из экспорта либо переписать докстринг под raw units.
- **[src/sim/models.js:319] `shell()` жёстко ставит `DoubleSide` для закрытых `makeCanister`/`makeCapsule`.** Прямо противоречит докстрингу `hullMaterial` («Only the open triangle-fan ships still ask for DoubleSide»). **Правка:** параметр по умолчанию `FrontSide`, ships передают `DoubleSide` явно.
- **[src/sim/models.js `makeFlame`] Комментарии инвертированы относительно геометрии** (широкое основание стоит у сопла, остриё уходит на `z=−L`, а не наоборот). Код визуально прав; чинить комментарий — иначе следующая правка «под комментарий» сломает пламя.

## Что хорошо

- **`userData.shared` / `disposeTree`** — контракт не только записан, а применён ровно там, где соблазн был (обломки); единая точка входа.
- **`edgeLines.onBeforeCompile`** — явный запрет имени `mvPosition` с объяснением, почему это ловит только браузер.
- **`probeContext` / stranded-путь** — никогда не бросает, возвращает `strandedApi`; no-WebGL спроектирован, а не обнаружен постфактум.
- **`BINDINGS` без пересечений кодов** (инвариант «одна клавиша — одно действие» соблюдён, есть тест), `CHART_LEGEND`/`TITLE_CONTROLS` сверены с `BINDINGS`.
- **Вывод в station.js только через `textContent`/`el()`** — XSS-путей нет; `revealScrollTop` и `wrap()` защищены от пустых/нечисловых входов.
- **`reputation.js`** — аккуратный слой: `decayWanted` бросает TypeError при потере индекса, `payFine` разнимает два ключевых пространства (и история в докстрингах объясняет, какой баг это закрыл).
- **Тесты и e2e разделены по сильным сторонам:** юниты — логика, e2e — длинный прогон с бюджетом кадра и ловлей накопления объектов.
